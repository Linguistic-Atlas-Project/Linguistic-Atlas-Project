## Project datasets

* Each ZIP in the repo root corresponds to **one LAP project**.  
* Archives contain only text-type formats: `txt csv xml xlsx xls doc docx`.  
* Very large projects are split into ≤ 25 MiB chunks (`…_partN.zip`).  

**Typical contents**

- *Responses* – survey answers from participants  
- *Informant details* – background information on contributors  
- *Interview transcripts* – recorded and transcribed sessions  

Datasets are refreshed periodically; ZIP filenames are overwritten when new data arrive.

## Data access & usage

### Extracting ZIPs

```text
Windows — right-click ▸ “Extract All…”
macOS   — double-click the ZIP
Linux   — unzip <file>.zip
````
